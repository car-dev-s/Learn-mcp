# 2. Why introduce a Repository?

In Phase 4, the MCP server directly accessed:

```python
customers
orders
```

We don't want the MCP layer doing SQL directly.

Avoid:

```python
@mcp.tool()
def get_customer(customer_id: int):
    connection = sqlite3.connect(...)
    cursor = connection.execute(...)
    ...
```

Instead:

```text
MCP Tool
   ↓
CustomerRepository
   ↓
SQLite
```

This gives us a clean separation:

```text
MCP layer
    │
    │ business-facing operations
    ▼
Repository
    │
    │ SQL
    ▼
SQLite
```

Later we can replace SQLite with PostgreSQL without rewriting all the MCP tools.

# 5. `database.py`

Create:

```text
phase05_sqlite/database.py
```

```python
import sqlite3
from pathlib import Path


DATABASE_PATH = Path(__file__).parent / "customer.db"


def get_connection() -> sqlite3.Connection:
    connection = sqlite3.connect(DATABASE_PATH)

    connection.row_factory = sqlite3.Row

    return connection


def initialize_database() -> None:
    with get_connection() as connection:
        connection.executescript(
            """
            CREATE TABLE IF NOT EXISTS customers (
                id INTEGER PRIMARY KEY,
                name TEXT NOT NULL,
                email TEXT NOT NULL UNIQUE
            );

            CREATE TABLE IF NOT EXISTS orders (
                id INTEGER PRIMARY KEY,
                customer_id INTEGER NOT NULL,
                product TEXT NOT NULL,
                amount REAL NOT NULL,
                status TEXT NOT NULL,
                created_at TEXT NOT NULL,

                FOREIGN KEY (customer_id)
                    REFERENCES customers(id)
            );
            """
        )
```

# 6. Understand `get_connection()`

```python
def get_connection() -> sqlite3.Connection:
```

Every repository operation can obtain a database connection through this function.

We use:

```python
connection.row_factory = sqlite3.Row
```

This allows us to access columns by name.

For example:

```python
row["name"]
```

instead of:

```python
row[1]
```

That's much easier to read.

# 8. `repository.py`

Create:

```text
phase05_sqlite/repository.py
```

```python
from database import get_connection
from models import Customer, Order


class CustomerRepository:

    def find_customer(self, name: str) -> list[Customer]:
        search_text = name.strip()

        if not search_text:
            return []

        with get_connection() as connection:
            rows = connection.execute(
                """
                SELECT id, name, email
                FROM customers
                WHERE name LIKE ?
                ORDER BY id
                """,
                (f"%{search_text}%",),
            ).fetchall()

        return [
            Customer(
                id=row["id"],
                name=row["name"],
                email=row["email"],
            )
            for row in rows
        ]

    def get_customer(self, customer_id: int) -> Customer | None:
        with get_connection() as connection:
            row = connection.execute(
                """
                SELECT id, name, email
                FROM customers
                WHERE id = ?
                """,
                (customer_id,),
            ).fetchone()

        if row is None:
            return None

        return Customer(
            id=row["id"],
            name=row["name"],
            email=row["email"],
        )

    def get_orders(self, customer_id: int) -> list[Order]:
        with get_connection() as connection:
            rows = connection.execute(
                """
                SELECT
                    id,
                    customer_id,
                    product,
                    amount,
                    status,
                    created_at
                FROM orders
                WHERE customer_id = ?
                ORDER BY id
                """,
                (customer_id,),
            ).fetchall()

        return [
            Order(
                id=row["id"],
                customer_id=row["customer_id"],
                product=row["product"],
                amount=row["amount"],
                status=row["status"],
                created_at=row["created_at"],
            )
            for row in rows
        ]

    def get_order(self, order_id: int) -> Order | None:
        with get_connection() as connection:
            row = connection.execute(
                """
                SELECT
                    id,
                    customer_id,
                    product,
                    amount,
                    status,
                    created_at
                FROM orders
                WHERE id = ?
                """,
                (order_id,),
            ).fetchone()

        if row is None:
            return None

        return Order(
            id=row["id"],
            customer_id=row["customer_id"],
            product=row["product"],
            amount=row["amount"],
            status=row["status"],
            created_at=row["created_at"],
        )

    def get_all_customers(self) -> list[Customer]:
        with get_connection() as connection:
            rows = connection.execute(
                """
                SELECT id, name, email
                FROM customers
                ORDER BY id
                """
            ).fetchall()

        return [
            Customer(
                id=row["id"],
                name=row["name"],
                email=row["email"],
            )
            for row in rows
        ]
```

# 9. Important SQL Lesson

Notice that we're using:

```python
WHERE id = ?
```

and:

```python
(customer_id,)
```

instead of constructing SQL like this:

```python
f"SELECT * FROM customers WHERE id = {customer_id}"
```

Never build SQL from untrusted input using string interpolation.

Use parameterized SQL:

```python
connection.execute(
    "SELECT ... WHERE id = ?",
    (customer_id,),
)
```

This is an important security habit.

```python
def seed_database() -> None:
    initialize_database()

    with get_connection() as connection:

        connection.executemany(
            """
            INSERT OR IGNORE INTO customers (
                id,
                name,
                email
            )
            VALUES (?, ?, ?)
            """,

        )

        connection.executemany(
            """
            INSERT OR IGNORE INTO orders (
                id,
                customer_id,
                product,
                amount,
                status,
                created_at
            )
            VALUES (?, ?, ?, ?, ?, ?)
            """,
            ORDERS,
        )

    seed_database()
    print("Database seeded successfully.")
```

# 13. `server.py`

Now connect the MCP server to the repository.

Create:

```text
phase05_sqlite/server.py
```

```python
import json

from mcp.server.fastmcp import FastMCP

from database import initialize_database
from repository import CustomerRepository


mcp = FastMCP("customer-sqlite-server")

repository = CustomerRepository()


# ============================================================
# Tools
# ============================================================

@mcp.tool()
def find_customer(name: str) -> list[dict]:
    """
    Find customers whose name contains the supplied text.
    """

    customers = repository.find_customer(name)

    return [
        {
            "id": customer.id,
            "name": customer.name,
            "email": customer.email,
        }
        for customer in customers
    ]


@mcp.tool()
def get_customer(customer_id: int) -> dict | None:
    """
    Get a customer by ID.
    """

    customer = repository.get_customer(customer_id)

    if customer is None:
        return None

    return {
        "id": customer.id,
        "name": customer.name,
        "email": customer.email,
    }


@mcp.tool()
def get_orders(customer_id: int) -> list[dict]:
    """
    Get all orders belonging to a customer.
    """

    orders = repository.get_orders(customer_id)

    return [
        {
            "id": order.id,
            "customer_id": order.customer_id,
            "product": order.product,
            "amount": order.amount,
            "status": order.status,
            "created_at": order.created_at,
        }
        for order in orders
    ]


@mcp.tool()
def get_order(order_id: int) -> dict | None:
    """
    Get an order by ID.
    """

    order = repository.get_order(order_id)

    if order is None:
        return None

    return {
        "id": order.id,
        "customer_id": order.customer_id,
        "product": order.product,
        "amount": order.amount,
        "status": order.status,
        "created_at": order.created_at,
    }


# ============================================================
# Resources
# ============================================================

@mcp.resource("customers://all")
def get_all_customers() -> str:
    """
    Return all customers as JSON.
    """

    customers = repository.get_all_customers()

    result = [
        {
            "id": customer.id,
            "name": customer.name,
            "email": customer.email,
        }
        for customer in customers
    ]

    return json.dumps(result, indent=2)


@mcp.resource("customers://{customer_id}")
def get_customer_resource(customer_id: int) -> str:
    """
    Return a customer resource as JSON.
    """

    customer = repository.get_customer(customer_id)

    if customer is None:
        return json.dumps(
            {
                "error": "Customer not found",
                "customer_id": customer_id,
            },
            indent=2,
        )

    result = {
        "id": customer.id,
        "name": customer.name,
        "email": customer.email,
    }

    return json.dumps(result, indent=2)


if __name__ == "__main__":
    initialize_database()
    mcp.run()
```

# 14. Notice the Architecture

The MCP tool:

```python
@mcp.tool()
def get_customer(customer_id: int):
```

doesn't know anything about SQL.

It calls:

```python
repository.get_customer(customer_id)
```

The repository knows SQL:

```python
SELECT id, name, email
FROM customers
WHERE id = ?
```

This gives us:

```text
                    MCP

                    │
                    ▼
             ┌──────────────┐

             └──────┬───────┘

                    ▼
```

# 24. Phase 5 Security Lesson

Never do this:

```python
sql = f"""
SELECT *
FROM customers
WHERE name = '{name}'
"""
```

For example, malicious input could alter the SQL.

Instead:

```python
connection.execute(
    """
    SELECT *
    FROM customers
    WHERE name = ?
    """,
    (name,),
)
```

The database driver handles the parameter safely.

This principle remains important when the input ultimately originates from an LLM.

Remember:

```text
User
 ↓
LLM
 ↓
MCP Tool
 ↓
Repository
 ↓
Database
```

The LLM is **not trusted input**.

# 27. What Phase 6 Should Add

The next logical step is **mutating tools**.

So far every operation is read-only:

```text
find_customer()
get_customer()
get_orders()
get_order()
```

Phase 6 should introduce:

```text
create_customer()
create_order()
update_customer()
cancel_order()
```

This is where MCP becomes more interesting from a **security and safety** perspective.

We'll cover:

* transactions
* validation
* duplicate customers
* invalid customer IDs
* state transitions
* rollback
* idempotency
* why an LLM should not blindly be allowed to perform destructive operations
* read-only vs mutating tools

That will set us up well for the later **LLM + MCP** phase.
